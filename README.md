## ✨ 주요 특징 및 설계 아키텍처

### 1. 관심사 분리 (Separation of Concerns)
빌드 도구나 별도 프레임워크 없이 순수 웹 표준(HTML5 / CSS3 / Vanilla JS)만으로 구성되어 어떤 정적 호스팅에서도 즉시 동작합니다.

```text
drops-lines-tiro/
├── index.html      # 시맨틱 마크업 뼈대 및 슬롯 구조
├── themes.css      # 공통 레이아웃 + 5대 공간별 테마 디자인 시스템
├── data.js         # 타임라인, 대중교통 노선, 티로 미션, 체크리스트 데이터
├── app.js          # DOM 동적 렌더링, 진행률 계산, localStorage 상태 영속화
├── .gitignore      # Git 추적 제외 설정
└── README.md       # 프로젝트 문서
```

### 2. 공간별 맞춤형 테마 시스템 (`themes.css`)
스크롤을 내리며 여정이 진행될 때마다 방문지의 정체성을 시각적으로 반영합니다.
* **`theme-kim` (김창열 화가의 집):** 황마 캔버스 노이즈 텍스처 + 반투명 물방울 글래스 배지 + 명조 타이포그래피
* **`theme-udon` (우동카덴 연희점):** 딥 인디고 네이비 노렌 감성 + 면발 아이보리 텍스트 + 붉은 인장(도장) 배지
* **`theme-park` (박서보미술관):** 한지 순백 배경 + 좌측 묘법(Écriture) 수직 반복 스트라이프 리듬
* **`theme-tiro` (Tiro After Meeting):** 실시간 녹음 맥박(`@keyframes pulse`) 배지 + 내부 4단 아젠다 타임 블록
* **`theme-transit` (대중교통 브릿지):** 수도권 버스·지하철 실제 도색(광역 레드, 지선 그린, 2·3호선 컬러) 뱃지 플로우

### 3. 티로(Tiro) 실시간 기록 워크플로우 통합
* **도슨트 전사:** 14:00 박서보미술관 정기 도슨트 해설 전체를 티로 앱으로 녹음·전사하여 아카이빙.
* **참관 후기 음성 메모:** 각 스팟 관람 직후 1~2분 음성 메모를 남겨 저녁 네트워킹 및 현장 인터뷰 시 실전 유스케이스로 활용.

## 🚀 GitHub Pages로 스마트폰에 띄우기

1. GitHub에 `drops-lines-tiro` 새 리포지토리를 생성하고 위 파일들을 푸시합니다.
2. 리포지토리 상단 메뉴에서 **`Settings` ➔ `Pages`**로 이동합니다.
3. **Build and deployment**의 Branch를 `main` (폴더 `/root`)으로 설정한 뒤 **`Save`**를 누릅니다.
4. 약 1분 후 생성되는 `https://<username>.github.io/drops-lines-tiro/` 주소를 스마트폰 사파리/크롬으로 열고 **'홈 화면에 추가'**를 누르면 네이티브 앱처럼 사용할 수 있습니다.
